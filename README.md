# Петушки — мобильный лендинг

Вёрстка по макету из Figma: **HTML + CSS + JS + GSAP**. Только мобильная версия.

## Параметры из макета

| Параметр | Значение |
|---|---|
| Фрейм | `iPhone Air - 1` — **420 × 5393 px** |
| Фон макета | `#F3F3F3` |
| Серые секции | `#D9D9D9` |
| Акцент (фиолетовый) | `#8A38F5` |
| Радиус карточек | `5px` |
| Отступ между карточками | `25px` |
| Зелёный (галочки/точки) | `#17C43C` |

## Структура

```
index.html          — разметка всех секций
css/style.css       — стили, mobile-first (база 420px)
js/main.js          — анимации: GSAP + ScrollTrigger, с фолбэком
assets/img/         — изображения (пока плейсхолдеры)
```

## Секции

1. **Hero** — «МОЛОДАЯ IT-КОМПАНИЯ», коллаж в стиле окон Windows, бегущая строка
2. **Наша команда** — 5 карточек: Мария, Лидия, Юлия, Виля, Вичеслав
3. **Наши преимущества** — 5 пунктов с анимированными галочками
4. **Услуги** — 4 карточки с индикаторами
5. **Промо** — промокод `ПЕТУШАРЫ`, скидка −20% с анимированным счётчиком
6. **CTA / футер** — «ВЛЕТАЙ В IT ВМЕСТЕ С НАМИ!» + контакты

## Анимации

- Появление секций при скролле (IntersectionObserver + CSS-transition)
- Каскадный въезд карточек услуг и преимуществ
- Галочки «прорисовываются» по очереди
- Окна коллажа покачиваются и двигаются с параллаксом (GSAP)
- Наклон карточек команды при появлении
- Счётчик скидки отсчитывает от 0 до 20
- Пульсация кнопки CTA
- Поддержка `prefers-reduced-motion`

### Принцип надёжности анимаций

Базовое состояние элемента в CSS — **видимое**. Скрипт лишь добавляет класс,
разрешающий анимацию (`.gsap-ready`). Если JS падает или не загрузился —
страница остаётся полностью читаемой, ни один блок не «зависает» невидимым.

## Замена изображений

В `assets/img/` сейчас плейсхолдеры. Чтобы поставить настоящие фото:

| Файл | Что экспортировать из Figma |
|---|---|
| `hero-1.png`, `hero-2.png` | `Group 5`, `Group 6` (коллажи в шапке) |
| `team-maria.png` | `Frame 3` |
| `team-lidia.png` | `Frame 4` |
| `team-julia.png` | `Component 1` |
| `team-vilya.png` | `Component 2` |
| `team-vicheslav.png` | `Group 2` |

Экспорт: выделить слой → **Export → + → PNG → 2x**. Имена файлов сохранить как в таблице.

## Локальный запуск

```bash
npx serve .
```

Сайт откроется на `http://localhost:3000`.
